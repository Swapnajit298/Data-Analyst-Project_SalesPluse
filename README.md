# 📊 SalesPulse – Retail Sales Analytics & Customer Insights

SalesPulse is an end-to-end retail sales analytics project designed to analyze
sales performance, customer behavior, product performance, regional trends,
and customer segments using Python.

The project transforms raw retail transaction data into actionable business
insights and an interactive dashboard.

---

## 🎯 Project Objective

The objective of SalesPulse is to analyze retail sales data and identify:

- Sales trends
- Best-performing products
- Product category performance
- Regional sales performance
- Customer purchasing behavior
- High-value customers
- Low-performing products
- Seasonal sales patterns

The project also uses K-Means clustering to segment customers based on
purchase value, purchase frequency, and average order value.
